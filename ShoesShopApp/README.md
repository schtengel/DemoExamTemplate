## 2. Чеклист по модулям

### М1. База данных (10 баллов, 50 мин)

- [ ] Данные импортированы без потерь: число строк в БД равно числу в файлах
- [ ] Ловушки данных обработаны: пустые строки, пробелы по краям, файл без заголовка, невозможные даты, дубли
- [ ] 3НФ: у справочников свои таблицы (категории, производители, поставщики, статусы)
- [ ] Первичные и внешние ключи, единый стиль имён
- [ ] ER-диаграмма в PDF: таблицы, связи, атрибуты, ключи

### М2. Приложение (15 баллов, 40 мин)

- [ ] Первое окно: вход и кнопка «Гость»
- [ ] ФИО в правом верхнем углу, кнопка «Выйти» ведёт на окно входа
- [ ] Карточка: фото, категория | наименование, описание, производитель, поставщик, цена, единица измерения, остаток, скидка
- [ ] Скидка **больше** 15%: фон `#2E8B57` (ровно 15% не подсвечивается)
- [ ] Есть скидка: старая цена красная и зачёркнута, итоговая чёрная рядом
- [ ] Остаток 0: голубая строка
- [ ] Нет фото: `picture.png`
- [ ] Заголовок окна, иконка приложения, логотип на главной форме
- [ ] Блок-схема по ГОСТ 19.701-90 в PDF
- [ ] Приложение не падает ни под одной ролью

### М3. Интерфейс, поиск, форма товара (25 баллов, 90 мин)

- [ ] Поиск по всем текстовым полям, в том числе по нескольким сразу, без кнопки «найти»
- [ ] Фильтр по поставщику, первый пункт «Все поставщики»
- [ ] Сортировка по остатку по возрастанию и убыванию
- [ ] Поиск, фильтр и сортировка действуют вместе
- [ ] Форма товара: клик по товару открывает редактирование, кнопка «Добавить товар» добавляет
- [ ] ID не виден при добавлении, при редактировании только для чтения
- [ ] Цена и количество не отрицательные, цена с сотыми
- [ ] Фото: до 300×200, в папку приложения, в БД путь, старый файл удалён
- [ ] Второе окно редактирования открыть нельзя
- [ ] Товар из заказа не удаляется, есть сообщение
- [ ] Список обновляется после любого изменения
- [ ] Окна сообщений: заголовок, иконка, понятный текст
- [ ] Кнопка «Назад» в каждом окне
- [ ] Комментарии только там, где код неочевиден

### М4. Заказы (25 баллов, 60 мин, только профильный уровень)

- [ ] Кнопка «Заказы» у менеджера и администратора
- [ ] Список по макету: артикул, статус, адрес, дата заказа, дата доставки
- [ ] Добавление, редактирование и удаление заказов только у администратора
- [ ] Все результаты загружены в репозиторий по ходу работы

## 3. Лёгкие баллы (по убыванию отдачи на минуту)

1. **Блок-схема (2 балла).** Механическая работа, фигуры известны, шаблон уходит минут на 5.
2. **Отладка (2 балла).** docx со скриншотами и отсутствие падений: нужен только проход по ролям.
3. **БД (10 баллов).** Предсказуема, если заранее отработаны ловушки данных.
4. **Оформление в М2 и М3.** Заголовки, иконка, логотип, окна сообщений с иконкой, кнопки «Назад»: каждый пункт бинарный и занимает секунды.
5. **Валидация в форме.** Отрицательные значения, обязательные поля, «ID только для чтения».
6. **Репозиторий и коммиты (М4).** Коммит после каждого модуля занимает минуту, а 23 балла завязаны на интеграцию.

**Дороже всего по времени:** фото с ресайзом и удалением старого файла, комбинированные поиск + фильтр + сортировка, форма заказа с составом. Делай их после всего перечисленного выше.

## 4. Как заучить код

Заучивай не файлы, а шесть шаблонов:

1. csproj и `App.xaml`: пакеты, `Resource`/`Content`, стиль окна с ключом
2. Пара «окно + ViewModel»
3. Список: `[ObservableProperty]`, вычисляемый `Products` с `NotifyPropertyChangedFor`, `Selected` и `OnSelectedChanged`
4. Форма: поля-строки, список ошибок, `Save`, `Delete`, `DialogResult = true`
5. Карточка в XAML: `DataTemplate`, триггер для зачёркнутой цены
6. Модель: `Include`/`ThenInclude`, partial-класс с вычисляемыми свойствами

### Ступени тренировки

| Ступень | Что делать | Критерий перехода |
|---|---|---|
| 1 | Перепиши код один раз, читая, и запусти | Приложение работает |
| 2 | Удали проект, оставь только список файлов и шаблонов, пиши по памяти; каждое подсматривание отмечай чёрточкой | Меньше 10 чёрточек на модуль |
| 3 | С чистого листа по таймеру: М1 за 50 мин, М2 за 40, М3 за 90, М4 за 60 | Отмечены все пункты чеклиста |
| 4 | То же на другом наборе данных (поменяй колонки и значения в xlsx) | Не выучил только свой набор |
